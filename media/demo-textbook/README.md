# Français interactif demo source

This demo uses chapter 1, “Bonjour!”, from *Français interactif* by Carl Blyth,
Karen Kelton, and Nancy Guilloteau, published by the Center for Open Educational
Resources and Language Learning (COERLL), University of Texas at Austin.

The COERLL catalogue identifies the curriculum as an open textbook under the
Creative Commons Attribution 4.0 International license (CC BY 4.0):
https://coerll.utexas.edu/coerll/oer/francais-interactif/

Source PDF:
https://www.laits.utexas.edu/fi/sites/default/files/Fi_chapter_1_ed4.pdf

Dialogue source:
https://media.la.utexas.edu:443/fi/aud/listening/01_ex12.mp3

Audio and video credits are listed by the project at:
https://www.laits.utexas.edu/fi/page/credits/

The application labels this material as a demo and keeps the attribution visible
in the demo tour. If the upstream project changes the license or removes an asset,
replace the bundled files and update this notice before release.
