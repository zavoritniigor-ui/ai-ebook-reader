# Third-party data

`js/cefr-lexicon-data.js` (CEFR levels for the reading statistics) is generated by `tools/build_cefr_lexicon.py` from:

- **CEFR-J Vocabulary Profile 1.5**, compiled by Yukio Tono, Tokyo University of Foreign Studies (http://www.cefr-j.org/). Free for research and commercial use with citation. Retrieved via Open Language Profiles (https://github.com/openlanguageprofiles/olp-en-cefrj).
- **Octanove Vocabulary Profile C1/C2 1.0**, Octanove Labs. CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
- **FLELex** (TreeTagger, Beacco version): François, T., Gala, N., Watrin, P. & Fairon, C. (2014), *FLELex: a graded lexical resource for French foreign learners*, LREC 2014; Pintard, A. & François, T. (2020). CENTAL, UCLouvain (https://cental.uclouvain.be/cefrlex/flelex/). CC BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/) — non-commercial use only.

The generated file keeps only the word → level mapping (lowest level per word); multi-word entries are dropped.

# Third-party software and models

`vendor/bergamot-3.0/` (the offline translator, `js/offline-translate.js`) holds two unmodified files of **bergamot-translator** (Marian neural machine translation compiled to WebAssembly) by the Bergamot project and Mozilla, **Mozilla Public License 2.0** (`vendor/bergamot-3.0/LICENSE`): the Emscripten glue `bergamot-translator.js` (v0.6.0, from https://github.com/mozilla/gecko-dev) and the engine `bergamot-translator.wasm` (the binary Firefox downloads; source https://github.com/browsermt/bergamot-translator and https://github.com/mozilla/translations). `vendor/bergamot-3.0/NOTICE.md` lists the exact sources and hashes.

The **language models** are not part of this repository: the app downloads them on the reader's request from Mozilla's public translation-model storage (Firefox Translations models, https://github.com/mozilla/firefox-translations-models, now https://github.com/mozilla/translations; MPL-2.0), through `functions/api/offline-model.js`, and verifies each file against the SHA-256 pinned in `js/offline-catalog.js` (generated by `tools/offline_models_catalog.py`).
