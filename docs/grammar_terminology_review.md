# Ukrainian grammar terms in the Rules catalogue — for a teacher to confirm

The Rules panel (js/grammar-rules-data-fr.js, js/grammar-rules-data-en.js) names each topic in Ukrainian. A linguistic
review (2026-11-15) checked the content of all 118 topics and corrected what was wrong; the **terms** below were not
changed, because the right choice depends on the textbooks the learners use. A teacher of French / English in Ukraine
should confirm or replace each one; then the names are changed in one place (the `T(...)` line of the topic).

| Topic (id) | Term used now | Question |
|---|---|---|
| fr `subjonctif-present`, `subjonctif-passe` | Сполучний спосіб | Ukrainian textbooks of French use «суб’юнктив», «сполучний спосіб» or «умовний спосіб». Which one? The English catalogue calls the English subjunctive «умовний спосіб» — the same Ukrainian name for two different moods in one app. |
| fr `conditionnel-present`, `conditionnel-passe` | Умовний спосіб | Fine if the subjunctive gets another name (row above). |
| en `subjunctive` | Умовний спосіб (subjunctive) | See the first row: keep «умовний», or «суб’юнктив»? |
| fr `imparfait` | Недоконаний минулий | «Імперфект» is the usual name in Ukrainian French grammars; «недоконаний» suggests the Slavic aspect, which the imparfait only partly matches. |
| fr `passe-simple` | Простий минулий | OK? |
| fr `plus-que-parfait` | Давноминулий час | OK (traditional). |
| fr `futur-anterieur` | Майбутній доконаний | «Передмайбутній» is also used. |
| en `present-perfect` | Теперішній доконаний | OK? Some textbooks keep the English name only. |
| en `past-perfect` | Передминулий | Or «минулий доконаний»? |
| fr `participe-present-gerondif` | Дієприкметник теперішнього часу та жерундій | The gérondif (en parlant) works like the Ukrainian «дієприслівник»; is «жерундій» the term learners will meet? |
| fr `pronoms-toniques` | Наголошені займенники | Or «самостійні займенники»? |
| fr `contractions` | Злиті артиклі | Or «злиті форми артикля»? |
| en `quantifiers` | Квантори | «Квантор» is a term of logic; Ukrainian English grammars say «слова на позначення кількості» or «кількісні займенники». |
| en `cleft` | Розщеплені речення | OK? |
| en `causative` | Каузатив | OK? |

Each topic also has an approximate CEFR level now (the `LEVELS` table in each data file, after the usual French CEFR /
DELF and English Profile syllabi). The teacher may adjust those too.
